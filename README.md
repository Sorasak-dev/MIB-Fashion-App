# MIB – Fashion Shopping Mobile Application

A Flutter-based mobile application for a fashion and clothing store, developed as an academic project at Mae Fah Luang University.

The application was designed to provide users with a mobile shopping experience where they can browse clothing products, explore brands, manage a wishlist, add products to a shopping cart, and go through the payment flow.

> **Project Type:** Academic Project  
> **Platform:** Android  
> **Framework:** Flutter  
> **Language:** Dart

## Overview

MIB is a fashion shopping mobile application developed as part of a university project.

The main goal of the project was to gain practical experience in mobile application development using Flutter and Dart while designing a shopping experience for a clothing store.

The application includes user authentication, product browsing, shopping cart, wishlist, payment-related screens, and user settings.

The Android application was also published on Google Play as part of the project.

## Getting Started

### Prerequisites

Make sure Flutter is installed on your machine.

Check your Flutter installation:

```bash
flutter doctor
```

### Installation

Clone the repository:

```bash
git clone https://github.com/Sorasak-dev/flutter_login2.git
```

Navigate to the project:

```bash
cd flutter_login2
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## Project Status

This project was developed as an academic project and is not intended to represent a complete production-ready e-commerce platform.

Some features may be implemented primarily as part of the application's user interface and academic demonstration rather than as a fully integrated commercial shopping system.

The project is published publicly as a portfolio example of my early experience with Flutter and mobile application development.
